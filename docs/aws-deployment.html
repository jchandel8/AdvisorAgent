    What the first deploy taught us

    GitHub's identity format

    GitHub sends repo:jchandel8@191924894/AdvisorAgent@1452303973:environment:demo, with permanent IDs. The role trusted the name only, so AWS refused. Found by reading the refused sign-in in CloudTrail.

    A required log setting

    ECS rejected the service without log_stream_prefix, although the Terraform provider marks it optional. terraform validate can't catch API rules like this.

    A provider bug that taints

    AWS filled in autoscaling defaults, the provider called it an error and marked the service tainted. Setting the values explicitly and running terraform untaint kept the healthy service and its URL.

    A URL that moves

    Each re-created Express service gets a new URL. The deploy now updates Cognito's allow-list itself, reading and re-sending the full client settings, because the update call resets anything not sent.
